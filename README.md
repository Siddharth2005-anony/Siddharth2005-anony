# Hello there!!

I am a **Data Science & AI/ML Engineer** focused on turning data and machine learning ideas into practical, deployable systems.

My interests span the complete journey from **data exploration and statistical analysis to machine learning, AI applications, and production deployment**. I enjoy working across disciplines rather than treating data science, machine learning, and software engineering as isolated areas.

### What I Build

I like building projects that connect multiple stages of the engineering lifecycle:

- **Data Science solutions** that transform raw datasets into meaningful insights, features, visualizations, and predictive models.
- **Machine learning systems** that focus on experimentation, evaluation, reproducibility, and measurable performance.
- **AI applications** using LLMs, RAG, agents, vector databases, and external tools.
- **MLOps pipelines** that take models beyond experimentation into tracked, reproducible, and deployable workflows.
- **Cloud-based applications** where ML and AI systems are exposed through APIs and deployed as real services.

### How I Approach Problems

I generally think about a problem as a pipeline:

**Data → Analysis → Features → Model → Evaluation → AI/ML Application → Deployment → Monitoring**

This allows me to approach problems from both the **data perspective** and the **engineering perspective**.

Rather than stopping at *"the model works"*, I am interested in questions such as:

- Is the data reliable and useful?
- Which features actually matter?
- How should the model be evaluated?
- Can the experiment be reproduced?
- How can the model or AI system be exposed through an API?
- How can it be deployed efficiently?
- How can the system be maintained and improved?

### Engineering Philosophy

> **Understand the data. Build the model. Engineer the system. Deploy it for real use.**

I believe strong AI/ML engineering requires more than knowing algorithms or frameworks. It requires understanding the **data behind the problem, the models built from it, and the systems that eventually serve those models**.

That is why I continuously work across **Data Science, Machine Learning, AI Engineering, and MLOps**, building projects that allow me to learn each layer while connecting them together.
